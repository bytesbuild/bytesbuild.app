# BytesBuild.app

Marketing landing page for **BytesBuild LLC** — a boutique software / product engineering studio at [bytesbuild.app](https://bytesbuild.app).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Google fonts: Syne + IBM Plex Sans / Mono

## Run locally

```bash
npm install
npm run dev
```

Dev server defaults to **http://127.0.0.1:3847** (uncommon port to avoid collisions).

```bash
npm run build
npm start -- -p 3847
```

## Project structure

- `app/` — App Router pages, global styles, metadata
- `components/BuildVisual.tsx` — full-bleed hero visual

## Design

Cool daylight “Blueprint Forge” direction: mist concrete atmosphere, electric teal signals, amber CTA heat, expressive Syne display type. See Project docs for the full brief.
